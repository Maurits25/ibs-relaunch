### B4 — AI-Crawl-Probleme bei Next.js App Router 2026

**Verifizierte Tatsache:** GPTBot, ClaudeBot, PerplexityBot, Bytespider, Meta-ExternalAgent **rendern kein JavaScript**. Sie holen rohes HTML und stoppen. Was nicht im initialen Server-Response steht, existiert für sie nicht.

**Pflicht-Maßnahmen für IBS-Stack (Next.js App Router, Netlify):**

1. **Default = Server Components.** Jede Seite ohne `"use client"`-Direktive rendert SSR. Genau das wollen wir.
2. **Client Components nur für Interaktion** (Formular-State, Header-Burger-Menu). Inhalte (H1, H2, P, Listen, Tabellen) immer Server.
3. **Dynamic Imports kritisch prüfen.** `next/dynamic` mit `ssr: false` macht Inhalt unsichtbar für AI-Bots. Nur für reine Widgets verwenden, nicht für Content.
4. **Streaming SSR / Suspense:** Stelle sicher, dass Bot-relevanter Content im initialen HTML-Chunk ist, nicht nachgeladen.
5. **Metadata API nutzen:** `export const metadata` pro Seite — Title, Description, OpenGraph, Twitter, canonical. App-Router's `metadata` ist SSR.
6. **`robots.ts` + `sitemap.ts`** im App-Router (file-based conventions):
   - `app/robots.ts` → exportiert robots.txt
   - `app/sitemap.ts` → exportiert sitemap.xml automatisch
7. **JSON-LD-Injektion server-side:**
   ```tsx
   // In jeder Page als Server Component:
   <script
     type="application/ld+json"
     dangerouslySetInnerHTML={{ __html: JSON.stringify(schema) }}
   />
   ```
   Niemals via `useEffect` clientseitig.
8. **Hydration-Test:** `curl -A "GPTBot/1.1" https://www.ibs-industriebodensanierung.de/ratgeber/kosten-bodenbeschichtung-pro-m2/ | grep "Epoxidharz"` — wenn der Begriff nicht im rohen HTML steckt, ist die Seite für AI-Bots blind.
9. **Netlify-spezifisch:** Edge Functions können SSR-Latenz reduzieren, aber sicherstellen, dass Cache-Header AI-Bots nicht ausschließen. `Cache-Control: public, s-maxage=3600` ist okay; aktive User-Agent-Sperren über Edge Functions vermeiden.
10. **Indexability-Probe-Check** (für CI/CD):
    ```bash
    # Test pro AI-Bot-User-Agent
    for UA in "GPTBot/1.1" "ClaudeBot" "PerplexityBot" "OAI-SearchBot"; do
      curl -A "$UA" -s -o /tmp/probe.html -w "%{http_code}" "$URL"
      grep -c "{{expected keyword}}" /tmp/probe.html
    done
    ```

### Typische False-Claims im Bodenbeschichtungs-Markt — KEINE dieser Aussagen ohne Beleg verwenden:

| Claim | Risiko | Korrekt formulieren |
|---|---|---|
| „lebensmittelecht" / „lebensmittelgeeignet" | UWG § 5: irreführend ohne EU-Verordnung 1935/2004-Konformität & Materialnachweis | „Migrationsarme Systeme für Lebensmittelverarbeitung verfügbar — Eignung wird projektspezifisch mit Materialhersteller geklärt." |
| „TÜV-zertifiziert" | UWG: TÜV ist Marke. Ohne konkretes TÜV-Zertifikat (Süd/Nord/Rheinland) abmahnfähig | „Materialien mit DIBt-Zulassung (abZ)" — DIBt nennen, nicht TÜV |
| „weltbeste / führende Beschichtung" | UWG § 5, alleinstehende Spitzenstellungsbehauptung | „Bewährtes System für…" / „etabliertes Verfahren" |
| „100 % chemikalienbeständig" | UWG § 5: keine Beschichtung ist gegen alle Chemikalien beständig | „Beständigkeit gegen [konkrete Stoffliste laut TDS]" |
| „diffusionsoffen" pauschal | irreführend wenn dampfsperrend | nur mit Sd-Wert-Beleg oder System-Bezeichnung verwenden |
| „lebenslange Garantie" | UWG + Werkvertragsrecht (§ 634a BGB max. 5 Jahre Verjährung) | „Realistische Lebensdauer 15–25 Jahre" + Gewährleistung gesetzlich |
| „zertifizierter Fachbetrieb" ohne Spezifikation | UWG § 5 falls keine valide Zertifizierung | „Fachbetrieb nach § 62 AwSV" — nur wenn Zertifikat vorliegt |
| „CE-zertifiziert" als Qualitätsmerkmal | nur Mindestkonformität, nicht Qualität — abmahnfähig laut IT-Recht-Kanzlei | gar nicht erwähnen oder „CE-konform" + Verweis Bauproduktenverordnung |
| Bilder von Fremdprojekten als eigene | UrhG + UWG | nur eigene Projekte, mit Freigabe Auftraggeber |
| Erfundene Kundennamen / Logos | UWG + MarkenG | nur Logos mit schriftlicher Freigabe |
| „klimaneutral" / „nachhaltig" ohne Beleg | seit 27.9.2026 verboten (EmpCo-Richtlinie/UWG-Novelle) | konkrete Belege (CO2-Bilanz, Zertifikat) oder weglassen |

### Was IBS gefahrlos sagen darf:
- „Über 20 Jahre Erfahrung" (verifizierbar über Geschäftshistorie)
- „Geführt von Daniel und Michael Schmäing"
- „Materialpartner Remmers, KLB, SIKA, Triflex" (wenn vertragliche Partnerschaft besteht — sonst „Wir verarbeiten Systeme von Remmers, KLB, SIKA, Triflex")
- „Fachbetrieb nach § 62 AwSV" — **nur wenn das Zertifikat tatsächlich existiert und gültig ist** (sonst weglassen!)
- „DIBt-zugelassene Systeme" (bezogen auf die Materialien, nicht IBS)
- „Sitz in Bocholt, Einzugsgebiet NRW + Niedersachsen"
- „Eigene Projekte aus [Branchen, in denen IBS tatsächlich gearbeitet hat]"

### Was IBS klären/intern verifizieren muss bevor publiziert:
- ⚠️ Existiert WHG-Fachbetriebs-Zertifikat (§ 62 AwSV) tatsächlich? Wer ist Ausstellender?
- ⚠️ Genaues Gründungsjahr (für `foundingDate` im Schema)
- ⚠️ Sind Remmers/KLB/SIKA/Triflex offizielle Partner oder „wird verarbeitet"-Beziehung?
- ⚠️ Welche Branchen-Referenzen sind explizit freigegeben (für Logos & Cases)?
